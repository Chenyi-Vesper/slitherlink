# 数回 MVP

需要 Node.js 22.6+。

    npm install
    npm run dev

打开终端显示的本地地址。生产构建：`npm run build`，核心验证：`npm test`。

React + TypeScript + SVG。点两个相邻顶点连线；切换擦除后点线段删除。支持 5–10 方形棋盘、首次连线开始计时、重开及新关卡。

生成器随机生长区域并计算全部数字，再以约束传播和回溯求解计数（最多两个解）验证唯一性；每次完整提示候选验证最多约 180ms，总生成预算 3.5 秒，最多 30 次尝试。独立 Worker 保持界面响应，主线程在 5 秒后强制终止并提供重试。随机移除约 38% 的数字提示，每次移除后重新验证唯一解；受时间预算限制时可能保留更多提示。空白格不限制线段数。胜利检查数字约束、顶点度数及连通性，不比对预设答案。
